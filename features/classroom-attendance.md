# 선생님용 학생별 출결

웹·Android·iOS에서 선생님 계정으로 로그인한 뒤 **학생 관리 → 담당 학생 → 출결**을 엽니다. 월별 출석률과 출석·지각·결석 건수, 수업별 입·퇴장과 참여 시간을 확인할 수 있습니다. **수정**에서 상태를 선택하고 필요할 때 사유와 메모를 저장합니다.

- 한국 시간 기준 예정 시작일이 선택한 월에 속하는 종료 수업을 최신순으로 표시합니다. 초대 전용은 초대 명단에 있는 수업, 공개는 입장 기록이 있는 수업을 포함합니다.
- 입장 기록이 있으면 출석, 초대 전용에서 입장 기록이 없으면 결석입니다. 지각은 선생님이 지정합니다. 출석률은 출석 건수를 전체 건수로 나눠 정수로 반올림합니다. 기록이 없으면 건수는 0, 출석률은 줄표를 표시합니다.
- 첫 입장·마지막 퇴장과 실제 참여 구간의 합계를 표시합니다. 겹치는 구간은 합치고, 종료된 수업에서 퇴장 시각이 열린 구간은 수업 종료 시각을 사용합니다.
- 수정값은 수업·학생별로 저장합니다. 상태, 선택 사유 한 개(기기 문제·네트워크·기타), 선택 메모 최대 500자를 저장하고 월별 집계에 즉시 반영합니다. 저장 실패 시 입력을 보존합니다.
- 담당 학생 관계와 수업 소유권은 서버에서 확인합니다. 저장 대상은 조회에 포함되는 수업으로 제한합니다. 학생 상세에는 출결만 표시합니다.

## 검증

저장소 루트에서 공통 검사와 영향받는 서버·웹 검사를 실행하고, `mobile/`에서 Android 핵심 테스트·빌드와 iOS 시뮬레이터 빌드를 실행합니다. 같은 데이터로 세 플랫폼의 휴대폰·태블릿 화면을 비교합니다. 실제 결과는 [변경 기록](changes/student-attendance.json)에 남깁니다.
