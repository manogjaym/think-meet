# 화상미팅 수업 시작과 모드 전환

선생님과 학생은 화상미팅에 먼저 입장해 영상·음성 통화하고 채팅합니다. 연결된 수업 소유자가 **수업 시작**을 누르면 수업 시간이 시작되고 수업방 모드가 열립니다. 학생에게는 시작과 모드 선택 버튼을 표시하지 않습니다.

- **수업방 모드**에서 선생님은 자신이 선택한 화면 또는 기존 수업 자료를 공유합니다. 브라우저 선택창, Android 캡처 동의, iOS ReplayKit을 사용합니다. 학습지는 기존 동선에서 이용합니다.
- **미러링 모드**에 들어가면 참석자 패널을 엽니다. 선생님은 연결된 학생을 직접 선택하며, 학생이 한 명이어도 요청을 자동 전송하지 않습니다. Android 학생의 승인·거절, OS 권한, 안내 포인터와 PiP는 기존 흐름을 사용합니다. [학생 화면 보기 흐름](meeting-laser-pointer.md)
- 공유나 요청이 있을 때 모드를 바꾸려면 종료를 확인합니다. 확인한 공유나 요청이 변경되면 최신 상태를 확인한 뒤 다시 시도합니다. 요청을 취소하거나 모드를 바꾸면 이전 요청의 승인과 캡처를 종료합니다.

## 상태와 호환성

수업 시작과 모드는 입장·출석과 별도로 저장합니다. 계약 revision 10의 수업 시작과 모드 변경 명령은 연결된 수업 소유자만 사용할 수 있습니다. 화면 공유와 미러링 요청은 서버가 모드와 권한을 검사합니다.

지원하는 선생님이 예약된 수업에 입장하면 준비 상태를 기록합니다. 기존 진행 중인 방과 구버전 선생님이 연 방은 기존 동선을 사용합니다. 시작 시각과 모드는 재입장 후에도 복원됩니다. 나가기·종료·공유 중지는 기존 권한으로 계속 정리할 수 있습니다.

## 검증 조건

웹·Android·iOS에서 교사와 학생으로 입장해 시작 전 통화, 교사 전용 버튼, 수업방 공유, 미러링 요청·승인·거절·취소, 전환 확인·취소와 재입장을 검사합니다. 같은 계정과 수업 상태에서 휴대폰·태블릿 화면을 비교합니다. [검증 기록](evidence/classroom-lesson-modes.md)
