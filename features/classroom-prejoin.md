# 입장 전 장치 점검

학생과 선생님은 웹·Android·iOS의 수업방 입장 준비 화면에서 카메라, 마이크, 스피커, 수업 서버 연결을 점검합니다. 기존 장치 설정을 불러오고 입장 시 적용합니다. 마이크 입력과 카메라 영상은 기기에서만 처리합니다.

예정 수업의 학생은 참여 버튼을 누르면 대기 화면으로 이동합니다. 수업을 개설한 선생님에게만 대기 학생 이름을 보여 줍니다. 장치 점검으로 돌아가거나 대기를 나가면 해제합니다. 갑자기 연결이 끊기면 서버는 마지막 갱신 20초 뒤 대기 표시를 지웁니다. 같은 학생의 여러 탭과 기기는 한 명으로 집계합니다. 선생님이 수업에 연결되면 기존 입장 흐름을 사용합니다.

장치 오류와 점검 결과는 화면에 표시합니다. 카메라와 마이크를 끄고도 입장을 요청할 수 있습니다. 스피커 버튼은 기기에서 테스트음을 재생하며, 네트워크 항목은 수업 서버 조회 응답 시간을 표시합니다.

## 검증

서버의 대기 권한·만료·다중 기기와 양쪽 역할의 입장 흐름을 확인합니다. 웹·Android·iOS는 같은 수업을 휴대폰과 태블릿에서 열어 권한·장치 오류, 영상·소리, 화면 이탈 후 정리를 검증합니다. 실행 결과와 미검증 범위는 [검증 기록](evidence/classroom-prejoin.md)에서 확인합니다.
