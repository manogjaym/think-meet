# 수업방 교재 불러오기

수업방에서 담당 선생님이 **수업 자료 → 교재**를 열어 자신이 올린 PDF와 쪽을 선택합니다. 두 열의 미리보기에서 쪽을 선택한 뒤 **화면에 불러오기**를 누르면 수업 참여자가 그 쪽부터 봅니다. 현재 교재와 쪽을 처음 선택하고, 공유 중인 PDF가 없으면 최근에 올린 PDF의 첫 쪽을 선택합니다. 자료 추가·삭제와 미디어 탭도 제공합니다.

| 항목 | 동작 |
|---|---|
| 위치 | 900px/dp 초과 화면에서는 왼쪽에 교재, 오른쪽에 참가자 영상과 교재 패널을 표시합니다. 작은 화면에서는 옆에서 패널을 열고 공유 성공 후 닫습니다. |
| 하단 도구 | 선생님의 PDF 아래에 쪽 이동, 지원되는 경우 화면 저장, 판서 도구를 표시합니다. |
| 권한 | 연결된 담당 선생님이 수업방 모드에서 본인 PDF를 공유합니다. 모드가 없는 수업은 기존 자료 공유 권한을 따릅니다. 학생은 기존 공유 스냅샷으로 봅니다. |
| 공유 | 같은 PDF는 공유 ID를 유지하고 쪽을 변경합니다. 쪽별 판서도 유지됩니다. 다른 PDF로 바꾸면 새 공유가 시작됩니다. |
| 오류 | 목록과 미리보기를 다시 불러올 수 있습니다. 공유 요청 실패 시 현재 화면과 선택을 유지합니다. |
| 호환 | revision 11의 `document.open`을 사용합니다. 구버전은 기존 수업 자료 흐름을 사용합니다. |

## 화면 검증

1. 분리된 검증 서버에서 같은 선생님·학생과 6쪽짜리 PDF를 사용합니다. 선생님과 학생이 같은 수업에 입장한 뒤 수업방 모드를 엽니다.
2. 선생님 화면의 수업 자료에서 PDF를 선택합니다. 두 열의 실제 미리보기에서 3쪽을 고르는 동안 기존 공유 화면이 유지되는지 확인합니다.
3. **3쪽 화면에 불러오기**를 누릅니다. 선생님과 학생의 첫 PDF 화면이 3쪽인지 확인합니다. 휴대폰은 교재 패널이 닫히고 태블릿은 참가자 영상 아래에 패널이 남아야 합니다.
4. 선생님 화면에서 쪽 이동과 판서 도구가 PDF 아래에 있는지 확인합니다. 펜으로 그리고 학생 화면에서 선을 확인합니다. 실행 취소, 다시 실행, 지우개와 다른 쪽에서 3쪽으로 돌아왔을 때의 판서 복원도 확인합니다.

iPhone에서 선택·공유·판서 검사를 자동 실행하려면, 시뮬레이터의 ThinkMeet 디버그 앱에서 **교재 페이지 검증** 수업의 입장 화면을 열어 둡니다. 수업은 미리 시작하고, 선생님 자료 목록에는 6쪽짜리 문서 하나를 준비합니다. `mobile/`에서 아래 명령의 `SIMULATOR_ID`를 해당 시뮬레이터 ID로 바꾸어 실행합니다.

```sh
xcodebuild -project iosApp/Tests/TextbookSmoke.xcodeproj -scheme TextbookSmoke \
  -destination "platform=iOS Simulator,id=$SIMULATOR_ID" \
  -parallel-testing-enabled NO CODE_SIGNING_ALLOWED=NO test
```
