# 선생님의 학생 마이크·카메라·판서 제어

화상미팅의 영상 아래에 마이크·카메라·판서 허용 버튼을 표시합니다. 다른 사람의 장치와 판서 권한은 수업 선생님만 바꿀 수 있습니다.

| 보는 사람 | 자기 영상 아래 | 다른 사람 영상 아래 |
|---|---|---|
| 선생님 | 마이크·카메라 | 학생: 마이크·카메라, 수업 모드에서 **판서 허용** |
| 학생 | 표시하지 않음. 하단 메뉴바의 마이크·카메라 사용 | 표시하지 않음 |

## 동작

- **마이크·카메라:** 선생님이 학생 버튼을 누르면 서버가 권한을 확인한 뒤 그 학생의 현재 수업 연결에만 `participant.media` 요청을 보냅니다. 학생 기기가 장치를 켜거나 끄고 "선생님이 마이크를 껐어요." 같은 안내를 표시합니다. 버튼은 LiveKit의 실제 송출 상태를 따르며 요청 중에는 비활성화합니다. 학생은 이후 자기 장치를 다시 바꿀 수 있습니다.
- **판서 허용:** 수업 모드(`instruction`)를 사용하는 수업에서 학생은 선생님이 허용해야 판서할 수 있습니다. 허용 여부는 수업 참여 정보에 저장되어 재입장 후에도 유지되고, 스냅샷의 `annotationAllowed`로 전달됩니다. 해제하면 학생의 판서 도구를 닫습니다. 선생님과 수업 모드가 없는 기존 수업은 항상 판서할 수 있습니다.

## 권한과 오류

| 조건 | 결과 |
|---|---|
| 학생이 `participant.control` 전송 | `FORBIDDEN` |
| 선생님이 화상미팅에 연결되지 않음 | `NOT_CONNECTED` |
| 대상이 선생님 본인·오프라인·퇴장 학생, 또는 연결된 기기가 revision 13 미만 | `PARTICIPANT_UNAVAILABLE` |
| 수업 모드가 없는 수업에서 판서 허용 변경 | `LESSON_MODE_REQUIRED` |
| 허용되지 않은 학생의 판서 추가·지우기·실행 취소·다시 실행·전체 지우기 | `ANNOTATION_NOT_ALLOWED`. 미리보기 선도 전달하지 않음 |

OS 권한이 없어 장치를 켜지 못하면 학생 화면에 오류를 표시하고, 선생님 버튼은 실제 상태를 유지합니다. 서버는 요청 전달만 보장하며 학생 기기의 장치 동작을 강제하지 않습니다.

## 호환성

계약 revision 13에 `participant.control` 명령, `participant.media` 이벤트, `MeetingParticipant.annotationAllowed` 선택 필드를 추가했습니다. 값이 없는 구버전 서버에서는 기존처럼 모두 판서할 수 있습니다. 수업 모드 수업의 구버전 학생 앱은 판서 버튼이 보여도 허용 전에는 서버가 거부합니다.

## 검증 조건

같은 교사·학생 계정과 수업 모드 수업에서 교사 화면의 버튼 표시, 학생 마이크·카메라 끄기·켜기와 학생 안내, 학생 화면에 영상 아래 버튼이 없음, 판서 허용·해제 후 판서 도구 표시를 휴대폰·태블릿에서 확인합니다. [변경 기록](changes/meeting-participant-controls.json)·[검증 기록](evidence/meeting-participant-controls.md)
