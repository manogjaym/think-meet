# 미러링 중 학생 기기 화면 위 판서

미러링(학생 원격 화면 보기) 중 선생님이 학생 화면에 펜·형광펜으로 그리면 Android 학생 기기의 실제 화면, 즉 학생이 보고 있는 다른 앱 위에도 같은 위치로 판서가 보입니다. 수업 모드에서 선생님이 그 학생의 판서를 허용하면 학생도 다른 앱 위 도구 막대로 자기 화면에 판서합니다. iPhone·iPad 학생에게는 판서할 수 없고 기존처럼 포인터만 사용합니다.

기능 ID는 `meeting.remote-annotation`, 계약 revision은 16, 검증 단계는 `in-progress`입니다. 구현된 기능은 환경변수 없이 기본 사용합니다. 미러링 자체의 요청·승인·포인터 규칙은 [학생 원격 화면 보기·안내](meeting-laser-pointer.md)를 따릅니다.

## 사용 흐름

1. 선생님이 미러링을 요청하고 학생이 승인합니다. 서버는 학생 연결이 **Android 앱이고 revision 16 이상**이면 세션에 `annotation: true`를 붙입니다. iOS 앱과 이전 버전 Android 앱은 `false`입니다.
2. `annotation: true`이면 선생님 웹·Android·iOS 앱의 공유 화면 아래에 **포인터·펜·형광펜·지우개**, 색상, 실행 취소·다시 실행, 전체 지우기를 표시합니다. 미러링을 시작하면 포인터가 선택되어 기존처럼 누른 채 움직이면 위치를 알려 줍니다.
3. 펜·형광펜을 고르고 그리면 기존 판서와 같이 그리는 동안 미리보기(`stroke.preview`)가, 손을 떼면 확정 판서(`stroke.add`)가 전송됩니다. 학생 화면 방향이 확정되기 전('화면 방향을 맞추고 있어요')에는 그릴 수 없습니다.
4. Android 학생 앱은 현재 공유·쪽의 선생님 판서만 골라 다른 앱 위 오버레이에 그립니다. 지우기·되돌리기·전체 지우기도 같은 방식으로 바로 반영됩니다. 학생은 판서 아래의 앱을 그대로 누를 수 있습니다.
5. `annotation: false`(iPhone·iPad·이전 버전 앱)이면 판서 도구를 숨기고 안내 문구로 "이 학생 기기에는 판서할 수 없어요. 학생 화면을 눌러 위치를 알려주세요"를 표시합니다.
6. 학생 화면 크기·방향이 바뀌면 서버가 공유의 쪽 번호(`share.page`)를 올립니다. 이전 방향의 판서는 선생님 화면과 학생 오버레이에서 함께 사라집니다.
7. 미러링 종료·캡처 중지·연결 끊김 등 기존 정리 조건에서 오버레이를 즉시 제거합니다.

## 학생 판서 모드

1. 수업 모드(수업방·미러링)에서 선생님이 미러링 중인 Android 학생 영상 아래의 **판서 허용**을 켜면, 학생 기기의 다른 앱 위 화면 아래 가운데에 도구 막대가 뜹니다. 구성은 **펜·지우개 | 파랑·빨강·검정 | 실행 취소**입니다.
2. 처음에는 펜과 파랑이 선택됩니다. 펜이나 지우개가 선택된 동안에는 화면 전체가 판서 입력을 받으므로 아래 앱을 누를 수 없습니다. **선택된 도구를 다시 누르면** 선택이 풀리고 아래 앱을 그대로 조작할 수 있습니다.
3. 학생이 그린 판서는 기존 판서처럼 저장되어 선생님 화면과 학생 오버레이에 함께 보입니다. 지우개는 학생 자신의 판서만 지우고, 실행 취소도 자기 판서만 되돌립니다.
4. 학생 쪽에는 닫기 버튼이 없습니다. 선생님이 **판서 허용을 끄면** 도구 막대와 학생 판서 입력이 함께 꺼집니다. 이미 그린 판서는 남습니다.
5. 도구 막대가 떠 있는 동안 PiP의 **화면 저장·미러링 끄기** 글자 버튼 바는 화면 아래 왼쪽으로 옮깁니다. 휴대폰 폭에서는 두 막대가 겹치지 않도록 도구 막대를 버튼 바 위에 둡니다.
6. 수업 모드가 없는 기존 방식의 방에서는 학생 판서 모드를 열지 않습니다.

## 권한·상태·통신

| 항목 | 규칙 |
|---|---|
| 판서 가능 세션 | 서버가 요청 시점의 학생 Socket 플랫폼(`android`)과 기능 지원(revision 16)으로 `AssistanceSession.annotation`을 정함. 클라이언트가 바꿀 수 없음 |
| 판서 권한 | 미러링 공유에는 해당 세션 선생님과, 수업 모드에서 선생님이 판서를 허용한 공유 학생 본인만 `stroke.add/erase`, `annotation.undo/redo/clear`, `stroke.preview` 가능. 다른 학생·허용되지 않은 공유 학생·기존 방식의 방·`annotation:false` 세션은 `ANNOTATION_NOT_ALLOWED`(미리보기는 전달하지 않음). 학생은 자기 판서만 지우고 되돌림 |
| 저장 | 기존 판서와 같이 공유 ID·쪽 단위로 DB에 저장되고 스냅샷으로 전달. 포인터는 계속 저장하지 않음 |
| 학생 표시 | 현재 공유·쪽, 삭제되지 않은 선생님·학생 본인 판서와 2초 안의 미리보기. 세션·공유·화면 크기 버전이 맞을 때만 표시. 학생이 그리는 중인 선은 기기에서 바로 그림 |
| 학생 도구 | 판서 허용(`MeetingParticipant.annotationAllowed`)·수업 모드·`annotation:true`·캡처 중일 때만 표시. 기존 `participant.control`의 판서 허용을 그대로 사용 |
| 회전 | 학생 화면 크기·회전이 바뀐 `assistance.geometry`에서 `share.page`를 1 올림. 같은 크기의 버전 갱신은 유지 |

계약 변경은 `AssistanceSession.annotation` optional 필드 추가뿐이며 새 API·Socket 명령은 없습니다. 배포 호환성 기준은 유지합니다.

## 플랫폼 조건과 한계

- **Android 오버레이:** 포인터와 판서를 화면 전체 크기의 창 하나에 그립니다. 같은 앱의 반투명 창 두 개가 겹치면 Android 12 이상의 터치 통과 기준(겹친 불투명도 합 0.8 이하)을 넘어 포인터 아래 터치가 막히기 때문입니다. 창은 터치·포커스를 받지 않고 투명도는 최대 0.8입니다. 보여 줄 포인터·판서가 없으면 창을 제거합니다.
- **학생 입력 창:** 펜·지우개가 선택된 동안 같은 전체 화면 창이 터치를 받습니다. 이 창이 도구 막대와 PiP 버튼 바를 덮지 않도록, 창을 새로 만들면 두 막대를 다시 띄워 맨 위에 둡니다. 시스템 PiP 창은 그 동안 누를 수 없으므로 펜 선택을 풀고 사용합니다.
- **도구 막대 폭:** Android는 내용에 맞추는 오버레이 창을 먼저 기본 대화 상자 폭(약 320dp)으로 재므로, 도구 막대는 40dp 버튼으로 그 안에 들어가게 만듭니다.
- **선 굵기:** 학생 기기에서 펜 4dp, 형광펜 18dp(38% 투명)로 그립니다. 앱 수업 화면의 판서와 같은 값입니다.
- **선생님 화면의 겹침:** 학생 오버레이도 화면 캡처에 포함되므로 선생님은 자기 화면에 그린 판서 아래로 캡처된 판서를 함께 봅니다. 위치는 같고 캡처 쪽 선이 대부분 더 가늘어 가려지지만, 형광펜은 조금 진하게 보일 수 있습니다.
- **보호 앱:** 설정 앱 홈처럼 외부 오버레이를 숨기는 앱과 시스템 UI 위에는 판서도 보이지 않을 수 있습니다(포인터와 같음).
- **iOS 학생:** 일반 앱이 다른 앱 위에 그리는 공개 API가 없어 지원하지 않습니다. iOS 선생님 앱은 Android 학생에게 판서할 수 있습니다(공통 Kotlin 화면).
