# 인프라 비용 항목

아래는 코드가 생성하는 비용 항목입니다. 실제 금액은 해당 리전과 사용량을 AWS 계산기에 입력해 확인합니다.

| 항목 | 계산에 반영할 값 |
|---|---|
| EKS | 환경별 클러스터 1개와 지원 버전 |
| EC2·EBS | 운영 앱 3대·미디어 6대, 테스트 각 1대. 운영 80GiB·테스트 30GiB 루트 디스크 |
| Aurora·Proxy | 환경별 DB 3대·저장량·I/O·백업·Proxy 사용량 |
| Redis | 환경별 두 그룹, 각 3대 |
| 네트워크 | 환경별 NAT 3대·공인 IPv4·VPC Endpoint·전송량 |
| 외부 접속 | ALB·NLB·CloudFront·WAF·Route 53·인증서 관련 사용량 |
| 저장·관측 | S3·KMS·Secrets Manager·CloudWatch·AMP·로그 보관량 |

테스트도 운영과 같은 네트워크·데이터 복제 구성을 사용합니다. 노드를 줄여도 전체 비용이 같은 비율로 줄지는 않습니다. 서버 배포 전에도 인프라 고정 비용은 발생합니다. 인터넷 전송량과 요청 수는 서버 담당자가 측정한 실제 사용량을 반영합니다.
